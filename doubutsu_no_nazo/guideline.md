## 5. 대본 규칙 (꼭 지킬 것)
- **인트로 훅을 처음부터 CSV에 넣기(가장 중요)**: 음성이 만들어진 뒤엔 대사를 추가하지 않으므로, 첫 15~25초 안에
  1) 0~3초: 가장 충격적인 사실 한 줄(여우), 2) 소년의 짧은 놀람 반응 2~4개(「え！？」「〇〇センチ！？」처럼 숫자·놀람), 3) 열린 질문(「じゃあ、なんで…？」), 4) 「その答え、今日ぜんぶ解き明かすわよ。」 같은 다리 문장 → 본편 시작.
  → **인트로의 구체적인 구성·원칙·샘플은 아래 8번 "인트로 지침"을 따른다.**
- 단서는 **단계적으로 공개**, 숫자·크기는 구체적으로(cm/m/kg/℃/수심), 사실과 추정은 분명히 구분(「～と考えられている」).
- 챕터는 ①~⑧ + まとめ. 챕터마다 "왜?" 질문 → 답 → 놀람 리듬.
- 사실 출처를 대본 끝(또는 별도 메모)에 목록으로 남기기(논문/연구기관/박물관 우선).
- 잔인한 묘사는 절제. 사람 사망 사고 등은 사실만 간결히.

## 5-1. 대본 문체·리듬 지침 (화식조 편 실제 대본 기준)
- **분량**: 약 650~720줄(화식조 694줄 = 20분 31초). 여우 약 63%, 소년 약 37%.
- **한 줄 길이**: 자막 한 줄 = 평균 11자, **최대 18자**(일본어 글자 수). 긴 문장은 의미 단위(、。 뒤나 조사 뒤)로 여러 줄에 나눔. 단어 중간에서 끊지 말 것.
- **여우(설명 담당)**: 부드러운 여성 말투 「～よ」「～わ」「～の」「～ね」, 숫자와 근거를 정확히(「時速およそ50キロ」「～とされているわ」「～と言われているの」).
- **소년(시청자 대변)**: 반말 「～じゃん」「～だね」「～の？」, 숫자를 되묻는 놀람(「50キロ！？」), 생활 비교(「原付バイクくらいじゃん」), 솔직한 감상(「逃げ切れる気がしないんだけど」).
- **리듬 패턴**: 여우가 사실 2~3줄 → 소년 놀람/비교 1~2줄 → 여우가 「しかも」「速さだけじゃないわ」로 한 단계 더. 이 "사실 → 놀람 → 더 센 사실" 계단을 챕터 안에서 반복.
- **숫자는 일상 물건과 비교**: 속도=자전거·원付, 높이=사람 키·농구 골대, 무게=쌀 포대, 길이=스마트폰 등(그래픽으로도 그리기 좋음).
- **챕터 시작**: 소년의 질문으로 열고(「でもさ、なんで○○なの？」), 챕터 끝은 다음 챕터로 궁금증을 넘기는 한 줄.
- **엔딩**: まとめ에서 핵심 5~6개를 짧게 되짚고, 마지막은 감정적 한 줄(보호·공존 등) + 다음 편 예고 느낌.
- **표기**: 동물명은 가타카나(ナマコ), 숫자는 아라비아 숫자, 단위는 한자/가타카나(センチ, キロ, メートル). 어려운 한자는 피하거나 쉬운 말로.

## 6. 화면(이미지·영상·모션그래픽) 규칙
- **사람 없음**: 이 채널은 사람을 등장시키지 않음(마네킹도 X). 프롬프트 끝에 `photorealistic nature documentary photograph, natural light, ultra detailed, 16:9 wide frame, no text, no watermark, no people` 형식 유지.
- 영상(vid) 프롬프트: 8초 한 장면, 카메라 움직임 동사는 **영상마다 서로 다르게**(push-in, orbit, tracking sideways, crane-up, drone drift…), `no text, no people`.
- `[그래픽: …]` cue로 **모션그래픽 요청**을 적어 주면 PC Claude Code가 코드로 직접 그림(화식조 편 수준 — 사용자가 "여태 최고"라고 칭찬한 방식):
  - X선/단면: 몸속 기관이 하나씩 빛나며 이름표가 붙는 해부도
  - 설계도: 연필선 윤곽 → 치수선(실측 cm) → 부품이 내려앉는 크기 비교
  - 지도: 실제 해안선·해구 지형 위에 서식지/발견 지점
  - 그래프: 선 → 숫자 → 결론 순서
  - 열화상·입자(생물발광, 먹물, 플랑크톤) 등
  - 예: `[그래픽: 단면도 — 해삼 몸속(입·장·호흡수·퀴비에관)이 하나씩 빛나며 이름표]`
- 배경음악은 PC 쪽에서 Google Flow Music으로 만듦(대본 세션은 신경 쓰지 않아도 됨).

## 8. 인트로 지침 (초반 이탈 방지) — 2026-10-18 추가

### 8-1. 배경
- 이 채널은 **초반 이탈이 심하다**(사용자 확인). YouTube 스튜디오(AI 분석)는 이 채널의 실제 시청 지속률 그래프를 볼 수 있고, 그에 따르면 [자기 뇌를 먹는 생물 편]은 시작 후 20~30초에 시청자의 약 40%, [머리 없는 바다민달팽이 편]은 1분 이내에 약 30%가 이탈했다. → **이탈 수치 자체는 실제 데이터로 본다.**
- 원인 해석(데이터에서 추론한 것): ① 정답(동물 이름)이 너무 빨리 나온다(멍게(ホヤ)가 29초에 공개됨). ② 도입 대화(「信じる？」「ありえない」 등 잡담)가 15~20초 이어져 핵심 충격이 뒤로 밀린다.
- 원인 해석은 추론이므로, 새 구조를 적용한 편의 지속률 그래프로 효과를 확인한다.

### 8-2. 구조 (0~60초)
| 구간 | 역할 | 구현 |
|---|---|---|
| 0~3초 | 충격적인 결과 한 줄 | 여우가 **인사 없이** 단정형으로 말한다. 화면은 제목이 약속한 가장 강한 장면 |
| 3~12초 | 놀람 연타 | 소년의 짧은 반응 2~4개. 숫자를 넣는다(「〇〇センチ！？」) |
| 12~25초 | 상식과의 모순 | "보통은 ~인데 이 생물은 ~". 구체적 숫자 하나 |
| 25~45초 | **번호 붙인 수수께끼 3개** | 謎①②③. 각 수수께끼를 회수할 챕터를 미리 정해 둔다 |
| 45~60초 | 다리 문장 → 정체 공개 | 「その答え、今日ぜんぶ解き明かすわよ。」 → 챕터 ①에서 동물 이름 공개 |

### 8-3. 원칙
1. **정체(이름)는 늦게, 원리(왜·어떻게)는 더 늦게.** 이름은 60초 안팎, 원리는 챕터 중반 이후.
2. **인사·잡담 금지.** 「こんにちは」「今日紹介する生き物は〜」 같은 말은 쓰지 않는다. 잡담 대신 소년의 숫자 반응.
3. **수수께끼에 번호를 붙이고, 어느 챕터에서 답할지 정해서 반드시 회수한다.** (예: ②→챕터 ③, ①→챕터 ⑤, ③→まとめ) 인트로에서 약속한 건 본편이 전부 답해야 한다. 부풀리면 중반에 오히려 이탈한다.
4. **화면은 8~10초마다 바꾼다.** 첫 3초는 충격 영상, 10초쯤 수치·크기 그래픽, 25초쯤 질문 텍스트 등.
5. **첫 문장은 질문형이 아니라 단정형.** 「信じますか？」보다 「〜するの。」
6. **한 줄은 최대 18자(평균 11자).** 5-1의 문체 지침을 따른다. 긴 문장은 의미 단위로 여러 줄에 나눈다. 말투는 여우=「～よ/～わ/～の」, 소년=「～じゃん/～の？」.
7. **정체를 대명사로 오래 숨기지 않는다.** 숨길 때는 "바다의 암살자" 같은 별명 대신 분류 힌트(「脳がない生き物」)를 조금씩 준다.
8. **사실과 추정을 구분한다.** 인트로에서도 「〜と考えられている」「種類によっては」를 쓴다.
9. **제목·썸네일과 첫 3초가 일치**해야 한다. 썸네일에 동물 이름이 이미 나와 있으면 이름 숨기기 전략은 효과가 작으니, 대신 "왜·어떻게"를 숨긴다.

### 8-4. 쓰면 안 되는 것
- YouTube가 제안한 예시(돌고래와 복어 "환각 파티", "청산가리의 1,000배", "1mg 사망")는 **구조만 참고하고 내용은 쓰지 않는다.** 과학적으로 미확인이며 수치도 검증되지 않았다(보류 주제).

```
여우,数週間から数か月で、
여우,また作り直すのよ。
소년,作り直す！？内臓を！？
여우,しかもこの生き物には、
여우,脳と呼べるものがないの。
소년,脳がないのに判断してるの！？
여우,ここには三つの謎があるわ。
여우,謎①、吐き出した内臓を、
여우,どうやって作り直すのか。
여우,謎②、なぜ命に関わるものを、
여우,自分から捨てるのか。
여우,謎③、研究者たちが
여우,この仕組みに注目する理由。
소년,ちょっと待って、全部気になる！
여우,その答え、今日ぜんぶ解き明かすわよ。
여우,まずはこの生き物の正体から。
```
- 내장 배출(자절)과 퀴비에관(끈끈한 실 모양 방어 기관)은 별개다. 인트로에서는 내장 배출만 다루고, 퀴비에관은 챕터에서 따로 설명한다.
- 재생 기간은 종마다 다르다. 정확한 숫자는 출처 확인 후 바꾼다.

### 8-6. 검증 방법

- 지속률 그래프(스크린샷)를 받으면 급락 지점에 맞춰 위 구간 길이를 조정한다.

## 9. 진행 중인 편: ロイコクロリディウム(달팽이 촉각 기생충) — 2026-10-18

### 9-1. 선정 경위
- 후보(해삼·불가사리·꼼치·숲개구리)와 YouTube 제안(딱총새우·물곰 등)을 비교한 끝에 **ロイコクロリディウム로 결정**했다.
- 일본에서는 이미 알려진 소재다(GIGAZINE 2007, 카라파이아, 메구로 기생충관 전시 등). 올해 YouTube 검색(인기순)에서 **전용 영상은 37~366회로 작고**, 큰 조회수는 "寄生虫" 총집편(24만)·노래(11만)처럼 큰 주제에서 나왔다. → 제목·썸네일에는 이름보다 **「寄生虫」「ゾンビ」** 키워드를 앞세운다.
- ヒトデ 검색은 올해 최고 1.1천 회로 수요 신호가 없었다.
- 기대치는 수백~수천 회. 롱폼 전에 쇼츠 1~2개(촉각 안에서 맥박 치는 애벌레)로 훅을 먼저 시험하는 것을 권장.
- 차별화: ① "분명한 것 / 아직 모르는 것" 구분(정확성) ② 일본 사례(지바현 채집, 오카모노아라가이, 메구로 기생충관 — 출처 확인 후 사용) ③ 생활환 지도·촉각 단면도 모션그래픽 ④ 1922년 주장(데이터 없음) → 2013년 야외 데이터 연대기.

### 9-2. 사실 확인 메모
- ✅ 성충은 새의 장에서 산다. 알은 새똥으로 나가고, 달팽이(오카모노아라가이류)가 똥을 먹어 감염된다. 촉각 안에 줄무늬 주머니(브루드삭)가 생겨 맥박치듯 움직이며 **애벌레처럼 보인다.** 벌레를 잡아먹는 새가 먹으면 다음 숙주로 옮겨간다.
- ✅ 2013년 폴란드 비아워비에자 숲 야외 연구(Wesołowska & Wesołowski, *Journal of Zoology*): 감염 달팽이가 더 높고 밝고 트인 곳에 있었다(감염 vs 비감염 비교).
- ⚠️ "조종하는 원리(어떻게)"는 아직 확립되지 않았다. 논문 초록도 과거 교과서 사례였지만 증명이 부족했다고 말한다. 1922년 독일 논문의 주장은 데이터가 없었다. → 「～と考えられている」「仕組みはまだ分かっていない」.
- ⚠️ 새가 주머니만 뜯고 달팽이가 살아남는다는 것은 사육 관찰 수준. 단정 금지.
- ❌ 쓰지 않기(출처 불분명): 맥박 40~75회/분, 달팽이가 3배 빨리 움직인다, 운동 뉴런을 장악한다, 맥박이 빛 세기에 맞춰 변한다.
- ❓ 일본 내 분포·감염률: 메구로 기생충관이 지바현에서 채집한 유충(오카모노아라가이 기생, 2023년)을 전시한 것만 확인. 종 수준은 "Leucochloridium属"로 표기.
- 발견 연도(1835년 등)는 일본 사이트 언급뿐이라 논문으로 확인 전에는 쓰지 않는다.

### 9-3. 제목 후보 (동물 이름 숨김)
1. 【衝撃】カタツムリの触角がイモムシに化ける…鳥に食べられに行く"ゾンビ寄生虫"の正体
2. 【衝撃】明るい場所へ自分から出ていくカタツムリ…触角の中の"イモムシ"の正体がヤバすぎる
3. 【衝撃】カタツムリの体の中で脈打つ"イモムシ"…その正体は鳥を目指す寄生虫だった

### 9-4. 챕터 구성안 (①~⑧ + まとめ)
| 챕터 | 내용 | 회수 |
|---|---|---|
| ① 正体 | 이름 공개, 생활환 전체 지도(새→똥→달팽이→새) | |
| ② 旅の始まり | 알이 새똥으로 나가 달팽이에게 먹히는 과정 | |
| ③ 触角の中の変身 | 촉각 단면도, 줄무늬 주머니가 생기는 과정 | **謎②** |
| ④ なぜ明るい場所へ | 2013년 폴란드 야외 연구, 감염 vs 비감염 비교 | **謎①** |
| ⑤ イモムシの罠 | 시각으로 사냥하는 새, 의태 | |
| ⑥ 鳥のお腹の中 | 성충이 되어 알을 낳는 순환 완성 | |
| ⑦ 本当に操っている？ | 원리 미해명, 1922년 주장과 2013년 데이터의 차이 | **謎③** |
| ⑧ 他の「操る」寄生虫 | ハリガネムシ 등 비교(출처 확인 필요) | |
| まとめ | 확실한 것 / 모르는 것 정리 | |
- 참고: 직전 천산갑 편의 소제목은 ①~⑦ + ⑧まとめ(총 8개)였다. 인수인계 문서는 ①~⑧ + まとめ. 이번 편은 문서 기준을 따르되, 사용자에게 확인한다.
