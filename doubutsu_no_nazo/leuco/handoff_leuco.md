> 참고: 화식조 편의 `handoff_hikuidori.md`는 대본 세션에서 직접 보지 못하고 인수인계 문서의 설명(형식·저장 위치·progress.csv·막혔을 때 규칙)에 맞춰 작성했다. 형식이 다르면 **화식조 때 형식을 우선**한다.

## 2. 작업 순서
1. **이미지 69장 생성(Google Flow)**: manifest의 type=image 행, `prompt` 열을 그대로 사용(수정 금지, 수정하면 progress.csv notes에 기록). 저장: `C:\Users\WF_25\Downloads\leuco_images\img_001.png` ~ `img_069.png`.
2. **영상 9개 생성(Flow, 8초)**: type=video 행. 저장: `leuco_images\vid_01.mp4` ~ `vid_09.mp4`. 카메라 동작은 영상마다 다르게 지정되어 있으니 바꾸지 않는다.
3. **진행 기록**: `leuco_images\progress.csv` — 열 `file,status,notes` (status = done / retry / skipped).
4. **모션그래픽 17개**: cues의 `[그래픽: …]` 행을 코드로 직접 그린다(화식조 편 수준). 아래 5번 숫자 규칙을 지킨다.
5. **효과음 13개**: `[SE: …]` 행. 합성 가능한 것은 직접 만든다.
6. **YMM4 조립**: 사용자가 `leuco_subtitle_v1.csv`로 음성을 만든 `.ymmp`를 넘기면, `subtitle_csv_row`(자막 줄 번호)와 `anchor_text`(그 줄의 일본어)를 기준으로 그림·영상·그래픽·효과음을 배치한다. 챕터 자막은 `[챕터자막: …]` 행 위치.
7. **배경음악**은 PC 쪽에서 Google Flow Music으로 만든다(대본 세션은 관여하지 않음).

## 3. 화면 규칙
- **사람 등장 금지**(마네킹·손·얼굴 포함). 생성 결과에 사람이 보이면 폐기하고 재생성.
- 이미지 프롬프트 끝의 `photorealistic nature documentary photograph, natural light, ultra detailed, 16:9 wide frame, no text, no watermark, no people`는 유지.
- 생성 이미지에 글자·워터마크(예: 도구 로고)가 보이면 제거하거나 재생성.
- 장면 이미지 켄 번즈는 줌인·줌아웃·좌우 팬·상하 틸트·대각선·약한 회전을 **섞어서** 사용(이전 편 피드백). 그래픽·인포그래픽은 정보 전달용이라 정적으로 둔다.
- 오프닝 후킹: 첫 3초에 `脈動音 + 縞模様の触角へゆっくり寄る`가 오도록 한다(천산갑 편의 입자 콜드오픈처럼 PC 쪽 판단으로 연출 추가 가능).

## 4. 그래픽에 쓸 수 있는 숫자 (이 외의 숫자는 넣지 않는다)
- 1922年(ドイツ論文の主張・データなし), 2013年(ポーランド野外研究), 2023年(目黒寄生虫館の展示 / Mishina他), 2024年(Sawada他), 2011年(ゾンビアリ研究)
- 約25cm(ゾンビアリが死ぬ葉の高さ), 約6時間(噛みついた後), 2〜3日後(子実体), ハリガネムシ数cm〜40cm
- 100〜250匹・約1.2mm は **「ある研究の報告・個体差あり」** の注記を必ず付ける。
- 脈打つ速さ・移動速度など**대본에 없는 숫자는 만들지 않는다**(출처가 없다). 맥박 속도·이동 속도 등이 그렇다。確かさの低い内容には「確認途中」「まだ不明」のラベルを付ける。

## 5. 막혔을 때 규칙
- 같은 프롬프트로 최대 3회 재시도 → 그래도 안 되면 `status=skipped`로 기록하고 다음 파일로 진행(전체 작업을 멈추지 않는다).
- 도구 제한·로그인 문제로 막히면 하던 파일 번호와 사유를 progress.csv에 적고 사용자에게 한 줄로 보고.
- 프롬프트가 거부되면 의미를 바꾸지 말고 표현만 완화(사람·손 등은 절대 추가하지 않음)하고 notes에 기록.
- 사실과 맞지 않아 보이는 그래픽 요구가 있으면 임의로 고치지 말고 `leuco_notes.md`의 출처를 보고 사용자에게 확인.
