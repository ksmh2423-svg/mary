### 크몽 상품에 없는 SellerFlow만의 강점 (상세페이지에 내세울 것)
- 도매매·오너클랜 **두 곳 가격을 비교해 더 싼 쪽을 고름** (상품 묶기)
- **시범 운영 모드 기본 ON**: 끄기 전에는 실제 마켓에 등록하지 않음
- API 키와 주문·개인정보를 **고객 PC에만 암호화해 저장**
- API 키 없이도 **CSV/엑셀 방식으로 먼저 사용** 가능
- 과일(신선식품) 모드, AI 상세페이지 (Phase 2 이후)

## 3. 서비스 방식에서 가져올 것 (SellerFlow를 '팔 때')

1. **등급 나누기** (Phase 3 라이선스·체험판에 반영)
   - 예시 구성: 기본(수집·가격계산·상품목록) / 표준(+상품명·이미지·필터·대량등록 엑셀) / 프로(+API 등록·재고·주문·알림)
   - 크몽 가격(5.5만~89만 원)은 참고만 하고, 가격은 언니가 정함
2. **제공 절차**: 상담(무료) → 기능 정의서 확인 → 중간 데모 → 고객 실제 환경에서 테스트 → 설치·사용법 안내 → 무상 유지보수 기간
3. **고객 준비사항 안내** (온보딩 마법사 Phase 3에 그대로 넣기)
   - 쓰는 도매처(도매매·오너클랜 사업자 회원 여부), 올릴 마켓, 판매자 유형(개인·사업자·법인)
   - 지금 손으로 하는 작업 순서, 하루 처리량, 가장 오래 걸리는 단계
   - 쓰던 대량등록 엑셀 양식, 마진율·배송비 기준, 로고·워터마크
   - 마켓 API 키 발급 (비밀번호는 받지 않음)
4. **주의 문구** (상세페이지·약관 초안에 넣기)
   - 수집은 공개 정보와 공식 API로만 하고, 로그인 우회·접근 제한 해제는 하지 않음
   - 대상 사이트 화면·정책이 바뀌면 유지보수가 필요할 수 있음
   - 상표권·인증 등 판매의 법적 책임은 판매자에게 있고, 프로그램은 걸러내기를 돕는 기능만 함
   - 정해진 도매처·마켓 수를 넘으면 추가 옵션

## 4. 따라 하지 않을 것
- **스마트스토어**: 두 상품 모두 지원하지만 SellerFlow 마켓에서 빠져 있음 (넣을지는 언니가 결정)
- **수익·마진 숫자를 약속하는 표현**: 쓰지 않기로 이미 정함
- **B의 "G마켓·옥션은 공식 API 미지원" 문구**: 사실인지 확인하지 못함. G마켓·옥션은 우선 대량등록 엑셀로 하고, API는 셀러 가입 후 공식 안내로 확인
- **A의 번역·관부가세·배송대행지 신청서**: 해외 구매대행용이라 지금(국내 도매처)은 제외. 해외 소싱을 붙일 때 다시 검토

## 5. 확인하지 못한 것
- 캡처에 보이는 내용만 보고 정리했고, 두 상품을 실제로 써 보지 않음 (실제 기능 수준·품질은 모름)
- B 페이지는 일부만 보였음 (수정·환불 규정, 상품정보고시 내용은 접혀 있어 보지 못함)
- 쿠팡·11번가·G마켓·옥션의 대량등록 엑셀 열 이름과 API 제공 범위, 도매매·오너클랜 API 문서는 확인하지 못함
