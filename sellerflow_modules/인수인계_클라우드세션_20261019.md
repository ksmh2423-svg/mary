## 4. 모듈 3개 요약 (함수 입력·출력)

| 모듈 | 주요 함수 | 입력 | 출력 |
|---|---|---|---|
| product_filter | `FilterRules.from_csv(path)` / `from_dicts(block=, trademark=, cert=, allow=)`, `check(fields, rules)` | `{"title":..,"brand":..,"category":..}` 또는 문자열 | `FilterResult(decision="block"/"review"/"pass", hits=[Hit(kind, word, field, note)])`, `.summary()` |
| title_cleaner | `TitleRules.from_csv(rules, settings)` / `from_dicts(...)`, `clean(title, rules, market=None, translate=None)`, `keywords(text, rules, extra="")` | 원본 상품명, 마켓 이름(coupang/11st/gmarket/auction) | `TitleResult(title, original, removed, truncated, keywords)` |
| image_square | `SquareSettings.from_csv(path)` / `from_dict(d)`, `make_square(pil_image, s)`, `square_bytes(data, s)`, `square_file(src, dest, s)` | PIL 이미지 / bytes / 파일 경로 | `SquareResult(image, source_size, content_box, warnings)` |

동작 메모
- product_filter: 띄어쓰기·대소문자 무시. 금지어→상표→인증 순, 긴 단어부터 검사하고 찾은 부분을 지워서 「전자담배」 안의 「담배」, 「충전기」 안의 「전기」가 중복으로 걸리지 않음. allow는 **위험 단어를 포함한 전체 문구**(예: 「무알콜 맥주」).
- title_cleaner: replace → 정규식 삭제 → 단어 삭제(긴 것부터) → 중복 단어 제거 → prefix → 글자 수 제한(단어 경계에서 자름). 번역은 함수를 넘겨받는 자리만 있음(한글이 없을 때만 호출).
- image_square: EXIF 방향 보정 → 투명 배경 채우기 → 흰 여백 잘라내기 → 정사각형 가운데 배치. 최대 확대 2배, 넘으면 경고. 인터넷에서 내려받는 기능은 없음(SellerFlow에서 받아서 넘길 것).
- 모든 설정 로더는 dict도 받으므로 SellerFlow의 `config.yaml` 값을 그대로 넘길 수 있음.

테스트 결과(클라우드, Python 3.13): **42개 전부 통과** (13 + 16 + 13). 각 폴더에서 `python -m unittest test_<모듈이름>`.

- 상품명 글자 수 제한과 세는 방식(글자/바이트) 미확인 → 기본 50자, 마켓별 칸은 비워 둠
- 상품명 금지 표현, 권장 이미지 크기·흰 배경 의무·용량 제한, AI 이미지 허용 여부 미확인
- "G마켓·옥션은 공식 API 미지원"(크몽 B 상품 문구)은 사실 여부 미확인

**도매처 (도매매·오너클랜)**
- 공식 API 문서 미확인, 실제 CSV의 열 이름·상품명 꼬리표·이미지 주소 형식 미확인 → 실제 파일로 `title_cleaner` 규칙 조정 필요
- 대괄호 통째 삭제 규칙 때문에 「[국내산]」 같은 정보도 지워질 수 있음

**금지어·상표·인증**
- 목록은 예시. 전기용품안전법·어린이제품법·식품위생법·화장품법·약사법·주세법·상표법, 각 마켓 판매금지 정책과 대조하지 않음
- 인증 대상은 단어가 아니라 상품 종류·사양으로 정해짐 → 이 모듈은 단어로 「확인필요」 표시만
- 「통과」가 법적 안전을 뜻하지 않음. 최종 책임은 판매자

**동작 한계**
- 단어 포함 방식이라 엉뚱하게 걸림 가능(아기→아기자기, 유아→유아인, LED→SLED) → allow로 막기
- 오타·초성(ㄴㅇㅋ)·특수문자 끼운 표기 못 잡음, 영문/한글 브랜드 표기는 따로 등록
- 상품명 중복 제거는 완전히 같은 단어만(「캠핑 의자」≠「캠핑의자」)
- 이미지: 흰 배경 기준 여백 자르기, 사진 속 글자·로고·워터마크 감지 없음
- 크몽 벤치마킹은 캡처만 보고 정리(실제 사용 X, B 페이지 일부 접혀 있음)
- 모든 모듈은 시험용 샘플로만 확인. 도매매·오너클랜 실제 상품으로는 미확인
